개인정보 처리방침

Lullog — 신생아 수유·수면·기저귀 기록 · 최종 수정 2026년 9월 19일 · 한국어 번역본 작성 2026년 9월 25일

이 한국어 문서는 이해를 돕기 위한 번역본입니다. 번역본과 영문 원문의 해석에 차이가 있으면 영문 원문이 기준입니다.

Lullog는 아기의 기록을 휴대폰 안에 보관합니다. 공유를 켜지 않는 한 어떤 것도 기기를 떠나지 않습니다. 계정도, 광고도, 분석 도구도, 추적도, 서드파티 SDK도 없습니다.

앱이 휴대폰에 저장하는 것

  • 아기의 이름과 생년월일(둘 다 선택 사항이며, 그냥 "아기"라고 두셔도 됩니다).
  • 남기신 기록: 수유(좌우, 시간, 분유 또는 유축량), 수면 시간, 기저귀 교체, 그리고 직접 적으신 메모.
  • 수유 방식이나 초기 설정 완료 여부 같은 설정값.

이 데이터는 iPhone 안에 있는 앱 전용 저장 공간에 보관되며, 평소의 iPhone 백업에 함께 포함됩니다. 앱이 iCloud에 따로 기록하지는 않으며, HealthKit도 사용하지 않습니다.

돌보는 사람과 공유(선택 사항, 기본값은 꺼짐)

Lullog는 배우자나 조부모, 돌봄 선생님이 아무것도 설치하지 않고 브라우저에서 기록을 보고 남길 수 있도록 비공개 웹 링크를 만들 수 있습니다. 이 기능은 설정 → 돌보는 사람과 공유에서 동기화 연결을 누르신 뒤에만 동작합니다. 그전까지 앱은 네트워크 요청을 전혀 하지 않습니다.

공유를 켜면 다음과 같습니다.

  • 아기의 이름, 생년월일, 수유 방식, 그리고 기록이 Cloudflare Workers와 Cloudflare D1에서 운영되는 저희 중계 서버로 전송되어 저장됩니다.
  • 접근은 무작위로 만들어져 추측할 수 없는 링크 토큰으로 통제됩니다. 링크를 가진 사람은 누구나 기록을 볼 수 있고, "보기와 기록 가능"으로 설정한 링크로는 기록을 추가할 수도 있습니다. 계정이나 비밀번호는 없습니다.
  • 서버는 기기들이 변경 내용을 합칠 수 있도록 각 기록에 기기별 식별자(iPhone에서 만든 무작위 ID, 웹으로 참여한 공동양육자의 경우 링크 토큰)를 함께 보관합니다. 이메일, 전화번호, 결제 정보는 저장하지 않습니다.
  • 어떤 링크든 언제든지 해제할 수 있습니다. 공유 중단는 모든 링크를 해제하고 네트워크 통신을 전부 멈춥니다. 기록은 휴대폰에 그대로 남습니다.

중계 서버는 초대하신 분들에게 기록을 보여 주는 데 필요한 것만 저장합니다. 저희는 그 내용을 읽지 않고, 팔지 않으며, 다른 용도로 쓰지 않습니다.

구매

Lullog Lifetime은 App Store를 통해 Apple이 전적으로 처리하는 1회 구매입니다. 저희는 결제 정보를 볼 수 없습니다. 이 거래에는 Apple의 개인정보 처리방침이 적용됩니다.

데이터 삭제

  • 휴대폰에서: 설정 → 모든 데이터 삭제를 누르면 모든 기록과 아기 정보, 모든 설정이 지워집니다. 앱을 삭제해도 마찬가지입니다.
  • 중계 서버에서: 설정 → 돌보는 사람과 공유 → 공유 중단 → 공유 중단 후 서버에서 삭제를 누르면 서버에 있는 기록 사본과 모든 링크, 아기 정보가 즉시 영구 삭제됩니다. 설정 → 모든 데이터 삭제도 휴대폰을 비우기 전에 같은 일을 합니다. 앱을 더 이상 갖고 계시지 않다면 공유 링크를 적어 메일을 보내 주세요. 30일 안에 삭제해 드립니다.

아동

Lullog는 아동이 아니라 부모와 양육자가 사용하는 앱입니다. 기록의 대상은 아기이지만, 앱은 아기로부터 어떤 정보도 수집하지 않으며 직접 입력하신 이름 외에 아이를 식별하는 어떤 정보도 수집하지 않습니다.

변경

앞으로의 버전이 여기에 적힌 것 이상을 수집하게 된다면, 그 버전이 출시되기 전에 이 페이지를 먼저 갱신하고 App Store의 앱 개인정보 보호 정보도 동일하게 맞추겠습니다.
